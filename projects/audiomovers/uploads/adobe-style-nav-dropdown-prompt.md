I'm working on low-fidelity wireframes for the Audiomovers website (an audio/video real-time streaming tool company — products include LISTENTO and GLIMPSE as flagship subscriptions, plus five smaller perpetual tools: OMNIBUS, AirCaster, Binaural Renderer, INJECT, MINIBUS). Match the exact wireframe style already used in the existing "Homepage Wireframe" and "Product page" files: greyscale boxes, placeholder image blocks labelled in caps (e.g. "HERO IMAGE — PRODUCT / CAMPAIGN"), Arial-style type, no colour, italic design-note callouts where a decision/behaviour needs flagging.

Build a nav mega-menu dropdown, styled like Adobe's "Solutions" dropdown pattern (a two-column list layout with a promo tile alongside), but scoped to Audiomovers' actual audience — not Adobe's enterprise verticals.

This dropdown replaces/restructures the existing "Sectors" item in the top nav (currently just a flat link in the wireframe top bar: "Downloads News Support Log in Try LISTENTO free Products Sectors"). Keep it in that same nav position — don't add a brand-new top-level nav item.

**Layout: two text columns + one promo tile, side by side, in a dropdown panel that opens on hover/click from the nav.**

**Column 1 — heading "Who it's for"**
- Individual & freelance creators
- Studios & businesses
- Education & students

**Column 2 — heading "Discipline"**
(reuse the same three categories and framing already used in the homepage's "Built for how your discipline works" section, so the two pieces of content stay consistent)
- Music — Mixing & production
- Film & TV — Post-production
- Games & broadcast — Live & interactive audio

Each column item is a simple text link (no icons needed at this fidelity). Do not duplicate any item across both columns — Adobe's own version repeats "Government" in both lists, which is a real usability flaw; keep these two axes mutually exclusive.

**Promo tile (right-hand side, roughly one-third of the panel width)**
A single placeholder image block with a heading and one CTA underneath, styled the same as the other placeholder image blocks in the existing wireframes (e.g. "PLUGIN UI IN DAW" style caption). Add an italic design note directly under it: *"Design note: swap per active campaign — e.g. Black Friday perpetual-product push, a GLIMPSE launch, or a trade-show feature. Not a fixed product."*

Keep the whole component at the same wireframe fidelity as the rest of the file — this is about structure and content hierarchy, not visual design.
