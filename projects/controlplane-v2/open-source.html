03 · Tool list · five tools, copy near-verbatim from current site
kubesec
github.com/controlplaneio/kubesec
Security risk analysis for Kubernetes resources.
Identifies misconfigurations and generates recommendations to improve the security of Pods, Deployments and other resources: find insecure configurations, harden security contexts, and learn Kubernetes pod security.
CLI · free API · kubectl plugin · GitHub Action · GitHub and GitLab marketplaces
netassert
github.com/controlplaneio/netassert
Network security testing for DevSecOps workflows.
A framework for fast, safe iteration on firewall, routing and NACL rules, for Kubernetes (network policies, services) and non-containerised hosts. Aggressively parallelises nmap to test outbound connections and ports from any accessible host, container or pod.
Kubernetes and bare metal · joins the network namespace under test
Simulator
github.com/controlplaneio/simulator
Kubernetes production breach simulation.
Provisions full, production-like infrastructure for attacking and debugging Kubernetes: a private cluster per player, scenarios demonstrating compromise paths, and training for defenders. The official CTF engine for every KubeCon since 2019.
Used to provision ControlPlane CTFs
BadRobot
github.com/controlplaneio/badrobot
Security analysis for Kubernetes Operators.
Analyses YAML manifests before deployment to detect high-risk configurations, and prevents compromised Operators from taking over a cluster through loose RBAC configurations.
Presented at KubeCon EU 2022
truffleproc
github.com/controlplaneio/truffleproc
Hunt secrets in a process’s memory.
A mashup of TruffleHog and gdb: analyses a target application’s memory and outputs discovered secrets and high-entropy strings. Useful for adversarial emulation, penetration testing, and testing defence-in-depth controls.
